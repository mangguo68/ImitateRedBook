## 🔧 技术栈

| 类别         | 技术/工具                                                                 |
|--------------|--------------------------------------------------------------------------|
| **前端**     | Vue 3 + TypeScript + Vite + Pinia + Vue Router + Axios                    |
| **UI 组件库**| Element Plus + Tailwind CSS                                              |
| **样式**     | SCSS（CSS 预处理器）                                                     |
| **后端**     | Express + MongoDB                                                        |
| **认证**     | JWT（JSON Web Token）                                                    |
| **部署构建** | Vite（支持快速开发与热更新）                                             |

🔗 **后端源码地址**：[ImitateRedBookBackend](https://github.com/mangguo68/ImitateRedBookBackend "仿小红书后端仓库")

## 🎯 项目亮点

- ✅ 前后端完全分离，接口规范清晰  
- ✅ 全站 TypeScript 开发，提升代码健壮性与可维护性  
- ✅ 响应式 UI 设计，兼顾美观与用户体验（Element Plus + Tailwind CSS）  
- ✅ 完善的用户交互体系：动态、评论、点赞、关注、通知等  
- ✅ 支持草稿箱管理、动态标签筛选、大图预览等高级功能  
- ✅ 支持主题切换（亮色 / 暗黑模式）与键盘快捷操作  

## 🧩 功能模块详解

### 👤 用户模块

#### 注册与登录
- 用户注册 & 登录（JWT 认证）
- 密码安全存储与验证

#### 个人主页
- 展示头像、昵称、红书号（用户 ID）、IP 属地等基本信息
- 动态概览：发布的笔记、获赞数、收藏数、关注数、粉丝数等

#### 个人信息维护（个人中心）
- 可编辑字段：
  - 头像、昵称、简介
  - 性别、星座、MBTI、学历、专业、兴趣爱好等
- 支持修改登录密码

#### 消息通知中心
- 通知类型：
  - 评论与 @ 提及
  - 点赞 & 收藏
  - 新增关注者
- 功能特性：
  - 未读通知高亮（红色标识）
  - 支持按类型/关键词搜索通知
  - 点击通知跳转至对应动态详情页
  - 一键标记全部为已读
  - 在“新增关注”中支持**一键回关**
  - 支持直接在通知中**回复评论**，实现高效互动


### 📝 动态模块

#### 浏览与互动
- 首页流式展示他人动态
- 支持按**标签筛选**或**关键词搜索**动态
- 动态详情页支持：
  - 查看所属标签（可点击跳转同标签动态）
  - 图片大图预览（支持多图）
  - 点赞 / 收藏 / 分享 / 关注作者
  - 点击用户头像跳转其个人主页

#### 发布动态
- 支持上传多张图片
- 填写标题、正文内容
- 选择分类 & 添加自定义标签
- **可保存为草稿** 或 **直接发布**

#### 草稿箱管理
- 查看 & 管理所有草稿
- 编辑草稿：修改图片、标题、内容、分类、标签等
- 删除草稿（防止误发）
- 支持：
  - 草稿搜索（按标题/内容）
  - 草稿分类筛选（如：未发布 / 已发布）

#### 动态管理（本人动态）
- 在动态详情页可：
  - 删除自己的动态
  - 收藏自己的动态（便于归档）
  - 分享动态链接（复制或社交分享）


### ⚙️ 系统设置模块

| 功能             | 说明 |
|------------------|------|
| **关于**         | 展示项目介绍、技术栈、作者信息 |
| **主题切换**     | 支持默认（亮色）与暗黑主题 |
| **修改密码**     | 安全修改账户密码 |
| **退出登录**     | 安全登出，清除本地认证状态 |
| **键盘快捷操作** | 可开启/关闭快捷键（如：`Ctrl+K` 快速搜索等），提升操作效率 |


## 🚀 项目目标

打造一个**高还原度、高性能、高扩展性**的小红书风格社区平台，既可用于学习全栈开发，也可作为毕业设计或作品集项目。


> 💡 **提示**：本项目前后端独立开发，前端通过 Axios 与后端 RESTful API 通信，建议配合后端仓库一同部署体验完整功能。
