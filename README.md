项目名称：基于VUE3+Vite的仿小红书项目
主要平台：PC端
项目描述：
- 基于VUE3+Vite的仿小红书项目，实现了用户注册登录、发布动态、点赞、评论、关注、消息等功能。
- 项目采用前后端分离架构，前端使用VUE3+Vite构建，后端使用Express+MongoDB实现。
- 项目采用JWT认证，保证用户信息安全。
- 项目采用Pinia管理状态，实现了动态的状态管理。
- 项目采用ElementPlus组件库，实现了美观的用户界面。
- 项目采用VueRouter实现了路由管理，实现了单页应用的效果。
- 项目采用Axios发送HTTP请求，实现了与后端的交互。
- 项目采用TypeScript编写，提高了代码的可维护性和可读性。
- 项目采用Vite作为构建工具，实现了快速的开发和热更新。
- 项目采用css预处理器SCSS，实现了更方便的样式编写和管理。
- 项目采用tailwindcss，实现了快速的样式编写和管理。

项目需求：
- 用户模块：
  - 用户注册登录功能
  - 用户个人主页功能
    - 用户基本信息展示，如头像、昵称、红书号（用户Id）、IP属地等
    - 用户可以查看自己的动态、点赞、收藏、关注、粉丝、获赞与收藏数量等信息
  - 用户信息维护
    - 用户可以在个人中心维护自己的个人信息，包括头像、昵称、简介、性别、星座、MBTI、学历、专业、兴趣爱好等
    - 用户可以修改密码
  - 用户通知功能
    - 用户可以查看自己的消息通知，包括评论和@、点赞、收藏、新增关注等
    - 用户可以在通知中心查看这几种类型的通知，包括已读和未读，未读通知会在通知中心显示为红色
    - 用户可以在通知中心搜索自己的通知，方便快速找到需要查看的通知
    - 点击对应的通知，会跳转到对应的动态详情页，用户可以查看通知的详细内容
    - 用户可以在通知中心一键已读通知，避免重复查看
    - 用户可以在新增关注中回关关注的用户
    - 用户可以在评论和@回复用户的评论，实现互动

- 动态模块：
  - 浏览和查看别人发布的动态
    - 用户可以在首页页查看其他用户发布的动态，搜索动态，根据标签筛选动态
    - 用户可以点击动态查看详情，包括评论、点赞、收藏、分享、关注等
      - 查看动态所属标签，用户可以根据标签筛选动态
      - 查看图片，支持大图预览
      - 用户可以在动态详情页点击其他用户的头像，查看其个人主页
  - 动态发布功能
    - 用户可以上传图片，填写标题、内容等，选择分类，添加标签
    - 用户可以保存草稿，后续可以在草稿箱中查看和发布，也可以直接发布
  - 草稿箱功能
    - 用户可以在草稿箱中查看和管理自己的草稿
    - 用户可以编辑草稿，包括修改图片、标题、内容、分类、标签等
    - 用户可以删除草稿，避免发布错误
    - 用户可以在草稿箱搜索自己的草稿，方便快速找到需要编辑的草稿
    - 用户可以在草稿箱中分类筛选草稿，包括未发布草稿、已发布草稿等
  - 动态管理功能
    - 用户可以在动态详情页删除自己的动态，避免发布错误
    - 用户可以在动态详情页收藏自己的动态，方便后续查看
    - 用户可以在动态详情页分享自己的动态，方便与他人互动

- 系统设置模块：
  - 关于
    - 展示项目介绍、技术栈、作者等信息
  - 主题
    - 用户可以在设置中选择不同的主题，包括默认主题、暗黑主题等
  - 修改密码
    - 用户可以在设置中修改密码，确保账号安全  
  - 退出登录
    - 用户可以在设置中退出登录，保护账号安全
  - 键盘快捷操作
    - 用户可以在设置中开启/关闭键盘快捷操作，提高操作效率
